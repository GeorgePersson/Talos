# Project governance

Talos is a community project maintained by [George Persson](https://github.com/GeorgePersson).
The maintainer reviews contributions, handles security reports and publishes
releases. Contributors receive credit through Git history and release notes.

Anyone can suggest improvements in Discussions, report bugs, improve docs,
test releases or submit pull requests. No contributor licence agreement is
required; contributions are provided under the project's MIT licence.

Discuss large changes before implementing them. Decisions consider a familiar
browser experience, dependable identity isolation, accessibility, maintenance
cost and support across Windows, macOS and Linux. Chromium DevTools and normal
Playwright APIs should handle the workflows they already cover well.

Maintainers make final scope and release decisions after considering community
feedback. An accepted suggestion is not a delivery promise. Regular contributors
may be invited to maintain parts of the project as it grows.
